# Greenhouse Monitoring System

## Project Description
The Greenhouse Monitoring System is an Arduino-based project designed to monitor temperature conditions inside a greenhouse.

## Components Used
- Arduino UNO
- Temperature Sensor
- LED
- Buzzer
- Connecting Wires

## Pin Connections
- Temperature Sensor - A0
- LED - D9
- Buzzer - D8

## Working Principle
The temperature sensor reads the temperature and sends the analog value to Arduino UNO.

Arduino converts the sensor reading into temperature. If the temperature exceeds the predefined limit, the LED and buzzer are activated as an alert.

## Technologies Used
- Embedded C
- Arduino IDE
- Arduino UNO

## Applications
- Greenhouse monitoring
- Agriculture
- Temperature monitoring
